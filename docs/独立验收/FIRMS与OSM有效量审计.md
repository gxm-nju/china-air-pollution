# FIRMS 与 OSM 有效输入体量审计

核验日期：2026-11-16。范围为现有输入的只读核算，没有补下载、修改主工程或推送。本审计独立于提交 4d39e62 的新增卫星与气象实验，不重复下载。

## 结论

FIRMS 的全国七年原始输入确实用于全国季节分布及固定热源掩膜，不仅用于长三角火点主分析。其相关输入有条件证明超过 200 MB，但不能把压缩派生表和原始表累加。OSM 目前明确可追溯的三份原始子集相加只有 113.50 MB，且仍有对象重叠；现有证据不能保证它作为第五个主要来源满足 200 MB。

课程原文使用“原则上不少于200 MB”，并允许自然较小但重要的地理边界等作为辅助源。该条款不等于已经批准把不足200 MB的来源作为第五主要源。是否调整主要/辅助来源需要按课程要求说明，不能靠无关下载凑量。

## FIRMS 实测

源目录为工程内 `多源数据与实验/data/raw/firms`，21份CSV，三个传感器2019—2025年。读取 `多源数据与实验/scripts/fires.py` 核对：实际读取 latitude、longitude、acq_date、acq_time、confidence、type、frp 七列；质量合格type0进入全国季节分布，type2另建固定热源表。跨传感器后按0.01度及30分钟格聚合，原始探测条数不等于独立火灾数。

| 计量对象 | 行数 | 字节 |
|---|---:|---:|
| 全部原始CSV文件 | 6,977,065 | 558,827,644 |
| 所有原始行的七个相关字段估值 | 6,977,065 | 303,526,100 |
| 质量合格type0、北京时间2019—2025内的原始整行 | 4,086,779 | 327,359,646 |
| 上述type0的七字段估值 | 4,086,779 | 177,877,606 |
| 质量合格type2原始整行 | 2,426,564 | 194,320,142 |
| 上述type2的七字段估值 | 2,426,564 | 105,497,346 |

type0和type2互斥，七字段估值合计 **283,374,952字节**。字段估值按照原文本字段长度，加每行6个逗号和1个LF计算，不含表头；这不是已落盘的283 MB文件，也不是压缩后大小。保留原始文本以避免补零、改变精度或重编码扩大容量。原始整行保留其他未用字段，不能与“仅相关字段”的严格口径混称。

检查中识别99条type0在UTC的2025年末，但北京时间已进入2026年，剔除后4,086,779行，与现有报告留存数一致。

作为范围对照，按UTC日期2023—2025及华东矩形27≤纬度<35、114≤经度<123，质量合格type0为141,999行，原始行11,387,916字节、七字段估值6,169,718字节。该诊断矩形不是行政区精确裁剪，也不是全部进入主模型的事件。它说明不能仅以长三角主Q1声称火点有效量超过200 MB。

### 仍需做的核验

将全国季节分析和固定热源掩膜的实际用途保留在报告中，并链接对应脚本、输出及输入清单。七字段估值可作为严格口径的辅助证据，但课程有效量最终宜用实际落盘的可追溯原始相关子集。需记录精确重复原始探测行检查；不同传感器观测同一场火灾属于需要聚合的观测，不宜简单视作重复文件，也不能作为多场火灾计数。

## OSM 实测

| 工程内相对路径 | 字节 | 用途 |
|---|---:|---|
| data/raw/osm/station_cells.osm.pbf | 30,769,620 | 实际计数的道路/工业对象及其引用几何 |
| 扩展实验/核验/农业用地参照.osm.pbf | 36,204,657 | 农田匹配核验 |
| 扩展实验/核验/行政区边界.osm.pbf | 46,530,135 | 行政归属核验 |
| 未扣重叠的算术合计 | 113,504,412 | 不是有效量最终值 |

`station_cells.osm.pbf`由 `scripts/osm_extract.py` 根据实际使用对象清单通过BackReferenceWriter提取，保留必要引用。全国与四省快照有地理重叠；不能把这些整档的1.87 GB视为研究有效量。三个子集之间也可能共享节点、道路或关系，文件SHA-256不同并不代表没有地理/对象重复。

建议下一步按对象类型、OSM ID及版本建立清单，合并必要引用后输出单份原始子集；记录每个对象服务哪个计算。历史版本不同不能不加判断地累加。此步骤未执行，本报告不宣称已经完成对象去重。

## 可复现与验证边界

在仓库根目录运行 `python3 scripts/audit_firms_osm_inputs.py --root /path/to/中国城市重污染日实验`，标准输出JSON，可由调用者保存。脚本只读取输入；输出逐文件大小和SHA-256、行及字段字节计数、三份OSM大小。它不解析OSM对象，不做空间去重，不生成数据子集，也不认证课程达标。

本轮数字来自Mac对现有文件的只读逐行扫描与stat。随附脚本将扫描整理成可复用版本；该整理版包含日期合法性检查和逐文件哈希，集成验收时已在 Mac 对 21 份 FIRMS 文件及三份 OSM 子集完成全量二次执行，数字逐项一致；结果见[FIRMS与OSM本机复核.json](FIRMS与OSM本机复核.json)。脚本不支持带引号的CSV，将明确报错，避免静默算错。

## 修复建议（已在独立副本验证）

用原指标完全一致的非SIMD运行捕获实际分折，不挑结果、不重新选择更有利折。将 shift=0/-1/+1 三套格点→fold 和格点样本数写入 no2_spatial_folds.json。读取清单时校验输入组与计数完全一致，并断言训练与测试城市、格点均不重叠。仍比较原始发布的18组结果，不修改数字或降低误差阈值。

集成文件：[模型脚本](../../scripts/extend_satellite.py)及[固定折分清单](../../data/cleaned/no2_spatial_folds.json)。

应用步骤：
1. 核实当前基线或人工合并脚本差异；先将JSON放到data/cleaned。
2. git apply frozen-folds.patch，若发布清单已变化则只合并脚本，按同样SHA256规则更新两行清单。
3. 正常CPU（无需禁用）分别以 PYTHONHASHSEED=1、97 执行 python reproduce.py。

本次两个hash种子默认CPU均全部通过（18组历史指标不变）；随后再次跑三年复核全部通过。报告和结果表未修改。补丁与JSON必须一起纳入发布，否则原来的CPU依赖分折仍可能出现。

## 修订图的复现

```bash
python 三年地面扩展/绘制结果图.py
python visualization/redraw.py
```

前者重画当前两面板图；后者仍按历史发布数据重画五张阶段图，输出到 `reproduced/figures/`。后者不能自动产生三年最新版。采集任务补齐新数据后，应重新冻结清单并重画最终核心图。

## 最终主图待办

为避免新旧版本混杂，建议最终统一呈现：最新覆盖热图、城市超阈空间分布、同日超阈时间图、火点日与未检出日对照、跨月预测误差、过程气象特征图。无需改变现有三个问题。每图注明范围、单位、来源及样本量，不按同一曲线的不同样式重复计数。

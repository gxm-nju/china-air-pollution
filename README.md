# 中国城市重污染日从哪里来？

**研究问题。** 2023—2025 年，长三角城市的重污染日集中在何时、何地？结合地面、卫星与气象观测，我们能解释哪些污染过程，又能在什么条件下更准确地监测地面 NO₂？

三年间，长三角 41 城在 **6 月、10—11 月的 10,898 个合格城市日中，日均 PM₂.₅ 超过 150 µg/m³ 的次数为零**。全季节 159 个超阈值城市日中，皖北、苏北 11 城占 98 个。2023 年 3 月 23 日五城地面粗颗粒凌晨陡升，与区域沙尘监测记录一致；模式细沙尘的同向变化提供了旁证。

全国站点档覆盖 2023—2025 年全部 1,096 天；长三角有 44,115 个达到每天至少 20 小时要求的合格城市日。6 月和 10—11 月用作收获参考窗口，各地实际焚烧时间有差异。零次超阈值仍允许焚烧影响低于阈值的城市日。皖北六市为蚌埠、淮北、亳州、宿州、阜阳、淮南，苏北五市为徐州、连云港、宿迁、淮安、盐城。

## 三个研究问题

|研究问题|样本与发现|
|---|---|
|火点出现后，下风城市的 PM₂.₅ 比上风多升多少？|全部 4,299 个事件中，第 12 小时下风比上风平均多升 3.91 µg/m³（95% 区间 +1.64 至 +6.38）。其中 1,566 个事件与同网格、同钟点未检出日配对，第 12 小时额外升幅为 +1.45 µg/m³，95% 区间 [−1.98, +4.99]。这批事件的上下风差为 +3.252，对照日为 +1.806。|
|加入气象信息，卫星估计地面 NO₂ 会更准吗？|用 2023 全年训练后，2024、2025 年的平均绝对误差分别下降 6.2% 和 3.7%。误差差值的按周 95% 区间分别为 [−0.52, −0.10]、[−0.42, +0.07] µg/m³。仅用一月训练时，两年冬季误差均降、春季均升，夏秋变化不确定。|
|重污染集中在哪里，哪些过程能找到来源线索？|159 个超阈值城市日合并为 120 段同城过程。6 段粗颗粒占优并增强、60 段 PM₂.₅ 与 CO 同升、27 段细颗粒占优且 CO 未明显升高，另有 17 段信号不一致或未达判据、10 段资料不足。3 月 23 日五城与 4 月 11 日淮北的粗颗粒特征均有外部沙尘观测佐证。[逐过程核验](三年过程污染物线索/逐城市过程.csv)|

旧火点样本 811 个事件的估计为 +9.61；在新表中重算同一批结果为 +9.59，新增 3,488 个事件平均 +2.59，合并后为 +3.91。[新旧对照与配对规则](docs/项目报告.md) · [三年实验记录](三年地面扩展/README.md)

## 离线复算

在包含 Python 3.12 的 macOS 或 Linux 环境中，先在终端运行以下命令。首次安装依赖需要联网。历史复算和三年核心指标各有独立入口。

```bash
git clone https://github.com/gxm-nju/china-air-pollution.git
cd china-air-pollution
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python reproduce.py
python visualization/redraw.py
python 三年地面扩展/复核结果.py
```

输出在 `reproduced/`。入口先校验发布清单，随后从 2023 年正月初一的站点读数重建 984 个城市小时，并逐项比对九个浓度、站数和气象字段。火点检验从发布的上下风对照表重算；卫星检验从 90 个区域日数组重建格点时刻并训练模型；连续污染过程从全国城市日表重新切分。五张图单独写入 `reproduced/figures/`。绘图环境需有支持中文的字体，如 Noto Sans CJK SC。PNG 成品可直接查看。

# 中国城市重污染日从哪里来？

**研究问题。** 2023—2025 年，长三角城市的重污染日集中在何时、何地？结合地面、卫星与气象观测，我们能解释哪些污染过程，又能在什么条件下更准确地监测地面 NO₂？

三年间，长三角 41 城在 **6 月、10—11 月的 10,898 个合格城市日中，日均 PM₂.₅ 超过 150 µg/m³ 的次数为零**。全季节 159 个超阈值城市日中，皖北、苏北 11 城占 98 个（61.6%）。2023 年 3 月 23 日五城地面粗颗粒凌晨陡升，与区域沙尘监测记录一致，模式细沙尘同向增加；2023 年 1 月初 9 段冬季个案中，TAP 估计硝酸盐、铵盐、硫酸盐三种二次无机盐合占 PM₂.₅ 增量的 66.0%。

全国站点档覆盖 2023—2025 年全部 1,096 天；长三角有 44,115 个达到每天至少 20 小时要求的合格城市日。皖北六市为蚌埠、淮北、亳州、宿州、阜阳、淮南，苏北五市为徐州、连云港、宿迁、淮安、盐城。

## 三个研究问题与主要发现

| 研究问题 | 样本与核心发现 |
|---|---|
| 火点出现后，下风城市的 PM₂.₅ 比上风多升多少？ | 全部 4,299 个事件中，第 12 小时下风比上风平均多升 +3.91 µg/m³（95% 区间 [+1.64, +6.38]）。其中 1,566 个事件与同网格、同钟点未检出对照日配对（火点日 +3.252，对照日 +1.806），逐对净差为 +1.45 µg/m³（95% 区间 [−1.98, +4.99]）。按聚集规模、收获参考月、南北区域和农田落点开展 8 组分层稳健性检验，点估计均正但 95% 区间全部跨零。[分层稳健性表](results/补充对照实验/Q1_配对事件分层稳健性.csv) |
| 加入气象信息，卫星估计地面 NO₂ 会更准吗？ | 在 36 个月、26,229 个匹配城市日上，仅用 2023 年 1 月训练的线性模型在冬季误差下降、春季误差上升。用 2023 全年训练原线性岭回归后，2024、2025 年 MAE 分别下降 6.2% 和 3.7%（2025 年按周区间 [−0.42, +0.08] 跨零）。补充对照实验表明，引入**季节交互项**（误差降 10.1% / 13.7%，R² 升至 0.708 / 0.701）或改用**非线性梯度提升树 HGBDT**（无季节降 8.1% / 10.6%，含季节降 13.9% / 19.2%）后，两年按日历周重抽样 95% 区间均严格低于零。[模型对照表](results/补充对照实验/Q2_非线性与季节交互对照.csv) |
| 重污染集中在哪里，哪些过程能找到来源线索？ | 159 个超阈城市日合并为 120 段同城过程，114 段（95%）始于冬季，皖北苏北 11 城占 61.6%（98/159），收获参考月零超阈。K-means 聚类将 116 段完整气象过程分为静稳低混合层（76 段）与输送条件（40 段）。多污染物分型识别出 60 段 PM₂.₅ 与 CO 同升、27 段细颗粒占优（CO 弱）、6 段春季粗颗粒增强；3 月 23 日五城与 4 月 11 日淮北获沙尘通报与 MERRA-2 印证，2023 年 1 月初 9 段个案中 TAP 三种二次无机盐合占 PM₂.₅ 增量的 66.0%。[逐过程核验](三年过程污染物线索/逐城市过程.csv) |

## 离线复算

在包含 Python 3.12 的 macOS 或 Linux 环境中，运行以下命令即可完整复算基线结果、补充对照实验及全套最终图表：

```bash
git clone https://github.com/gxm-nju/china-air-pollution.git
cd china-air-pollution
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python reproduce.py
python scripts/supplement_experiments.py
python visualization/generate_final_figures.py
python 三年地面扩展/复核结果.py
```

## 数据规模与分层台账

本研究整合 7 个独立数据源（4 个核心主源 + 3 个辅助源）：
- **核心主源**：CNEMC 地面监测日档（1,998.8 MB，PM₂.₅ 与 NO₂ 原始记录行 257.07 MB）、NASA FIRMS 七年全国火点表（558.8 MB）、ECMWF ERA5 三年区域网格（266.22 MB）、Sentinel-5P 三年 36 个月原生 L2 区域提取（1,688 份非空区域文件共 196.28 MB）。
- **辅助源**：OpenStreetMap 沪苏浙皖农田/道路/行政边界子集、NASA MERRA-2 区域气溶胶与边界通量个案（16 份）、TAP 10 km 化学组分日均与月均网格。

详细口径与校验清单见 [数据源与关联](data_sources.md)、[三年跨季节核验](非一月卫星补采_验收/实验日志.md) 及 [项目报告](docs/项目报告.md)。
